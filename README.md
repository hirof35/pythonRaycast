# Geometric Collision Simulator (Pygame)

Pygameを用いて、異なる幾何学的形状（円、矩形、三角形）の移動および衝突判定をリアルタイムでシミュレーションするプログラムです。

## 概要
マウスドラッグによって形状を移動させ、形状同士が重なった際の色変化（ビジュアル・フィードバック）を通じて、背後で動いている衝突判定アルゴリズムの挙動を確認することができます。

## 実装されている衝突判定アルゴリズム
本プロジェクトでは、各形状の特性に合わせた数学的アプローチを採用しています。

*   **Circle vs Rectangle (円と矩形)**:
    矩形上の「円の中心に最も近い点」を特定し、その点と円の中心との距離をピタゴラスの定理（`math.hypot`）で計算。距離が半径未満であれば衝突と判定します。
*   **Point in Triangle (点と三角形の内外判定)**:
    外積を利用した「サイン（符号）判定」を実装。三角形の各辺と点との位置関係を計算し、点がすべての辺の同じ側にあるかどうかで三角形の内部にあるかを判定します。
*   **Rectangle vs Triangle (矩形と三角形)**:
    矩形の各頂点が三角形の内部に含まれているかを走査することで判定を行います。
*   **Circle vs Triangle (円と三角形)**:
    円の中心が三角形の内部にあるかを確認するロジックを実装しています。

## 主な機能
*   **インタラクティブなドラッグ＆ドロップ**: 
    `pygame.MOUSEMOTION` と `move_ip` を活用し、各オブジェクトを自由に配置可能。
*   **リアルタイム・ステータス表示**: 
    衝突状態に応じて、形状の色が動的に変化（青/緑 → 赤）。
*   **相対移動ロジック**: 
    `event.rel` を用いることで、マウスの動きに合わせたスムーズな追従を実現。

## 動作環境
*   **言語**: Python 3.x
*   **ライブラリ**: Pygame

## 導入手順
1.  **依存ライブラリのインストール**
    ```bash
    pip install pygame
    ```
2.  **実行**
    ```bash
    python collision_detection.py
    ```

## 操作方法
*   **ドラッグ**: 形状を左クリックしたまま動かすことで移動できます。
*   **離す**: クリックを離すと移動が終了します。

## システム構成
*   **描画**: 60FPSベース（ハードウェア依存）のリアルタイムレンダリング。
*   **座標系**: スクリーン座標（左上を原点とする800x600の領域）。
*   **数学処理**: `math` モジュールによるベクトル・距離計算。

## 今後の拡張予定 (Roadmap)
*   **分離軸定理 (SAT) の導入**: 凸多角形同士のより汎用的な衝突判定の実装。
*   **衝突応答 (Collision Response)**: 衝突した際に形状がめり込まないよう押し戻す物理計算の追加。
*   **円と三角形の厳密な判定**: 現在の「中心点のみの判定」から、三角形の辺と円の交差を含めた完全な衝突判定へのアップグレード。
